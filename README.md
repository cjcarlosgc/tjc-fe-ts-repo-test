# MiniERP

Pequeño ERP empresarial para gestión comercial y operaciones.

## Stack
TypeScript, React, Vite, React Router, Vitest, React Testing Library y ESLint.

## Módulos
Customers, Products, Inventory, Sales Orders y Shipping.

## Comandos
`npm install` · `npm run dev` · `npm test` · `npm run build` · `npm run lint`

La lógica de dominio está separada de React y usa servicios mock asíncronos en memoria.
